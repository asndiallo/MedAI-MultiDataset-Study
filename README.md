# MedAI-MultiDataset-Study

A collection of case studies exploring AI applications in healthcare, part of my Master's research at IPSSI Paris.

## Overview

This repository contains my research work applying machine learning to various medical datasets. Each case study explores a different healthcare challenge, from data preprocessing to model evaluation.

## What's Inside

```
notebooks/           # Main research notebooks
  notebook1/
    README.md       # Study details
    analysis.ipynb  # Code and results
  notebook2/
    ...

assets/             # Images and resources
```

## Research Areas

- Data preprocessing for medical datasets
- Machine learning model selection and application
- Feature engineering for healthcare data
- Performance analysis and evaluation

## Getting Started

1. Each notebook folder contains:
   - A README explaining the healthcare challenge
   - A Jupyter notebook with analysis and results
   - Any additional resources needed

2. Notebooks are self-contained and documented for easy review

## About Me

I'm completing my Master's in Big Data and AI at IPSSI Paris (graduating January 2024). This research is part of my thesis work exploring AI applications in healthcare.
